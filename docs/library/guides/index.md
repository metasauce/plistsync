# Guides

In-depth guides for using `plistsync` from Python.

Almost everything is the same for every service: a library is built from a service config,
tracks are found through the lookup interfaces, and playlists are edited through `edit()`.
Where a service differs, its page under {doc}`Services <../../services/index>` has the details.
